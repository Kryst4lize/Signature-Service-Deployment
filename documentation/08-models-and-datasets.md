### 1.2 CycleGAN Dataset (`data/cyclegan_unprocessed_data/`)

Used to train the CycleGAN denoiser (and to evaluate the verification models).

| Property | Value |
|----------|-------|
| **Path** | `trainingfiles/data/cyclegan_unprocessed_data/` |

| **Test persons** | 21 genuine + 21 forged = 42 folders |

| **Test images** | 500 files |

### 1.3 Verification Dataset (`data/verification_unprocessed_data/`)

Used to train the VGG16 and ResNet50 classifiers (and subsequently the extractors).

| Property | Value |
|----------|-------|
| **Path** | `trainingfiles/data/verification_unprocessed_data/` |
| **Total persons** | 238 folders (genuine + forged) |
| **Total images** | 4,289 files |
| **Naming** | `NNN/` (genuine) + `NNN_forg/` (forged) |
| **CSV files** | `data.csv` (85,247 rows) — all pair combinations |
|  | `train_data.csv` (76,722 rows) — training pairs |
|  | `test_data.csv` (8,525 rows) — test pairs |

#### CSV format

```csv
image_a_path, image_b_path, label
001/001_00.png, 001/001_01.png, 1       ← genuine pair (same person)
001/001_00.png, 001_forg/001_forg_02.png, 0  ← forged pair
```

- `label = 1` → genuine pair (same person)
- `label = 0` → forged / impostor pair

> **Note:** The `_forg` folders are automatically **excluded** during classifier training
> by `verification_dataset_preparation.py`. Only genuine folders are used as class labels.

### 1.4 Stamp Noise Data (`data/stamp_noise_data/`)

Vietnamese official stamp/seal images used for CycleGAN data augmentation.

| Property | Value |
|----------|-------|
| **Path** | `trainingfiles/data/stamp_noise_data/` |
| **Count** | 16 stamp images |
| **Format** | JPG/PNG |
| **Content** | Vietnamese round seals, company stamps, official seals |
| **Used by** | `stamp_augmentation.py` → `StampAugmentor` class |
| **Source** | Collected manually (internal) |

Features applied during augmentation:
- DPI-aware scaling (36–42mm stamp @ 150–300 DPI)
- Red ink tinting for greyscale stamps
- Partial visibility (stamp bleeds off crop edge)
- Random opacity (50–92%)
- Rotation jitter (±12°)

## 2. Pretrained Backbone Weights

ImageNet-pretrained weights used as initialisation for fine-tuning. These are NOT trained
by us — they are downloaded from Keras Applications.

| File | Path | Size | Source |
|------|------|------|--------|
| `vgg16_weights_tf_dim_ordering_tf_kernels.h5` | `model/` | 528 MB | [Keras VGG16](https://keras.io/api/applications/vgg/#vgg16-function) |
| `resnet50_weights_tf_dim_ordering_tf_kernels_notop.h5` | `model/` | 90 MB | [Keras ResNet50](https://keras.io/api/applications/resnet/#resnet50-function) |

> These weights are used by `train_verification.py` via `--vgg16_weights` and `--resnet_weights` flags.
> If the weights files are not present locally, Keras will attempt to download them from the internet.

## 3. Trained Model Files

### 3.1 CycleGAN Checkpoints

| File | Size | Description |
|------|------|-------------|
| `latest_net_G_A.pth` | 43.4 MB | Generator A: clean → noisy (not used in production) |
| `latest_net_G_B.pth` | 43.4 MB | Generator B: noisy → clean ★ **deployed** |
| `latest_net_D_A.pth` | 10.6 MB | Discriminator A (training only) |
| `latest_net_D_B.pth` | 10.6 MB | Discriminator B (training only) |

**Location (training):** `pytorch-CycleGAN-and-pix2pix/checkpoints/signature/`
**Location (copy):** `convert_model/original_model/`

**Architecture:** ResNet-9-blocks generator (CycleGAN standard)
- Input: `[1, 3, 224, 224]` — noisy signature
- Output: `[1, 3, 224, 224]` — cleaned signature
- Parameters: ~11.4M

### 3.2 Verification Models (Fine-tuned)

#### VGG16

| File | Size | Description |
|------|------|-------------|
| `vgg16_finetuned.keras` | 1,028 MB | Full classifier (with classification head) |
| `vgg16_extractor.keras` | 448 MB | Feature extractor only ★ **deployed** |

- **Backbone:** VGG16 (ImageNet pretrained, all layers fine-tuned)
- **Output dimension:** 4096-d (FC1 layer)
- **Parameters:** ~134M total (backbone) + classification head
- **Preprocessing:** Caffe-style BGR mean subtraction

#### ResNet50

| File | Size | Description |
|------|------|-------------|
| `resnet50_finetuned.keras` | 248 MB | Full classifier (with classification head) |
| `resnet50_extractor.keras` | 123 MB | Feature extractor only ★ **deployed** |

- **Backbone:** ResNet50 (ImageNet pretrained, BN layers frozen)
- **Output dimension:** 4096-d (added FC1 after GAP)
- **Parameters:** ~23.6M (backbone) + Dense(2048→4096) + classification head
- **Preprocessing:** Caffe-style BGR mean subtraction

**Location (training output):** `model/verification_model/`
**Location (copy):** `convert_model/original_model/`

### 3.3 YOLOv8s (Detection)

| File | Size | Description |
|------|------|-------------|
| `yolov8s.onnx` | 42.6 MB | Pre-exported ONNX (original) |

- **Source:** [Ultralytics YOLOv8s](https://github.com/ultralytics/ultralytics)
- **Task:** Signature region detection in document pages
- **Input:** `[1, 3, 640, 640]`
- **Output:** `[1, 5, 8400]` bounding boxes
- **Not fine-tuned** — uses the pretrained YOLOv8s weights

## 4. Deployed ONNX / TensorRT Models

These are the final files deployed in the Triton model repository at
`signature-verification-service/triton/model_repository/`.

| Model | ONNX Size | TensorRT Size | Input Shape | Output Shape |
|-------|-----------|---------------|-------------|--------------|
| `yolov8s` | 42.5 MB | 52.1 MB | `[1,3,640,640]` | `[1,5,8400]` |
| `latest_net_G_A` | 43.5 MB | 75.8 MB | `[1,3,224,224]` | `[1,3,224,224]` |
| `latest_net_G_B` | 43.5 MB | 75.8 MB | `[1,3,224,224]` | `[1,3,224,224]` |
| `resnet50_extractor` | 121.9 MB | 124.1 MB | `[1,3,224,224]` | `[1,4096]` |
| `vgg16_extractor` | 448.1 MB | 491.8 MB | `[1,3,224,224]` | `[1,4096]` |

**Total deployed size:** ~1.5 GB (ONNX + TensorRT combined)

> Triton will prefer `.plan` (TensorRT) over `.onnx` if both are present.
> TensorRT gives 2–5× faster inference but is GPU-architecture-specific.
